# PPC Karnataka Planner

Map, stamp tracker and cycling trip planner for Karnataka's Permanent Pictorial Cancellations:
the 106 Philately Passport sites plus other known PPCs.

## Files
- `index.html`, `app.js`, `style.css`: the site (no build step)
- `data/sites.json`: PPC reference data (generated by `make_site_data.py` in the parent project)
- `data/progress.csv`: your stamps (`id,site,stamped,date,booklet_page,notes`), written by the app
- `data/state.json`: trips, settings and per-post-office hours, written by the app

## Enable saving from the app
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate.
2. Repository access: **Only select repositories** → this repo.
3. Permissions → Repository → **Contents: Read and write**. Nothing else.
4. In the app: Settings → GitHub sync → fill Owner, Repo, Branch (`main`) and paste the token → **Sync now**.
   Do this once on each device. The token is stored only in that browser.

Without a token the site still works read-only from the committed data, and edits stay on that device.
Every save is a commit, so the history of `data/progress.csv` is your stamping log.
