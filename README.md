# Karnataka Philately Passport

Map and stamp tracker for the 100 Permanent Pictorial Cancellation sites in the Karnataka Philately Passport booklet,
plus unconfirmed extras from the community list (hidden by default). Each person signs in and keeps their own progress.

## Files
- `index.html`, `app.js`, `style.css`: the site (no build step)
- `data/sites.json`: site data (generated by `enrich_booklet.py` in the parent project from the Excel checklist)
- `.github/workflows/pages.yml`: deploys to GitHub Pages and writes `firebase-config.js` from the `FIREBASE_CONFIG` secret
- `firestore.rules`: security rules to paste into Firestore (each user can only read/write `users/{their uid}`)

## Storage
Progress lives in Firestore at `users/{uid}` as `{ progress: { p001: {stamped, date, notes}, ... }, name, updated }`.
Without a Firebase config the site runs in local-only mode (browser storage). Account tab → Export CSV for a backup.

## Deploy setup (once)
1. Settings → Pages → Source: **GitHub Actions**.
2. Settings → Secrets and variables → Actions → New repository secret `FIREBASE_CONFIG` = the web config as JSON:
   `{"apiKey":"…","authDomain":"…","projectId":"…","storageBucket":"…","messagingSenderId":"…","appId":"…"}`
3. Every push to `main` redeploys. Locally (no config file) the site runs in local-only mode.
