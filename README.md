# Karnataka Philately Passport

Map and stamp tracker for the 100 Permanent Pictorial Cancellation sites in the Karnataka Philately Passport booklet,
plus unconfirmed extras from the community list (hidden by default). Each person signs in and keeps their own progress.

## Files
- `index.html`, `app.js`, `style.css`: the site (no build step)
- `data/sites.json`: site data (generated by `enrich_booklet.py` in the parent project from the Excel checklist)
- `.github/workflows/deploy.yml`: deploys to Firebase Hosting on every push to `main`
- `firebase.json`, `.firebaserc`: Firebase Hosting / Firestore project config
- `firestore.rules`: security rules to paste into Firestore (each user can only read/write `users/{their uid}`)

## Storage
Progress lives in Firestore at `users/{uid}` as `{ progress: { p001: {stamped, date, notes}, ... }, name, updated }`.
Without a Firebase config the site runs in local-only mode (browser storage). Account tab → Export CSV for a backup.

## Deploy setup (once)
Hosted on Firebase Hosting: https://ppc-karnataka.web.app. Firebase Hosting serves the web config at
`/__/firebase/init.json`, so no config file or config secret is needed.
1. Firebase console → Project settings → Service accounts → **Generate new private key** (downloads a JSON file).
2. GitHub repo → Settings → Secrets and variables → Actions → New secret `FIREBASE_SERVICE_ACCOUNT` = the whole JSON file. Then delete the downloaded file.
3. Every push to `main` deploys (`.github/workflows/deploy.yml`). Firestore rules: paste `firestore.rules` in the console, or `firebase deploy --only firestore:rules`.
